# Вело-контроллер

Программа для Windows: блокирует компьютер, если не крутить педали велотренажёра (данные приходят с Arduino по COM-порту).

## Как выглядит работа

- Как только начинается вращение педалей, окно сворачивается в круглый спидометр (по умолчанию 50 px) в левом нижнем углу видимой части экрана. Его можно перетащить, но вынести за экран нельзя.
- Стрелка на 12 часах - установленная скорость. Шкала: от 0 до удвоенной нормы.
- Кружок зелёный, пока скорость и нагрузка не ниже нормы. Ниже нормы - жёлтый, и чем ближе блокировка, тем краснее. Серый - покой.
- Внешнее кольцо - сколько осталось до дневного норматива. Число в центре - зачтённые минуты.
- Когда дневной норматив выполнен: звук, фейерверк, надпись «Ура! Норматив выполнен! Я супер!» и приложение скрывается до следующего дня (или до изменения норматива в настройках).
- Размер кружка меняется в настройках (30-200 px).
- Перед началом вращения показывается приветствие: календарь за последние 3 месяца, в дни с выполненной нормой стоит жёлтый лайк, внизу - число тренировочных дней и пройденные километры. Километры считаются по оборотам колеса диаметром 19 дюймов (окружность около 1,516 м). Километры записываются с версии 4, за более ранние дни их нет.

Настройки открываются двойным щелчком по окну (пароль администратора). Если приложение скрыто или нужен вход: `Ctrl+Alt+Shift+P`.

## Установка на компьютер

1. Скачайте из последнего релиза (раздел Releases) `VeloController.exe` и `INSTALL_VELOCONTROLLER.bat` в одну папку.
2. Запустите `INSTALL_VELOCONTROLLER.bat`. Он копирует программу в `%LOCALAPPDATA%\VeloController` и создаёт задание Планировщика: запуск при входе и повторная попытка каждые 10 минут.
3. Смените пароль администратора в настройках (по умолчанию в коде задан пароль для первого запуска).

## Обновление с GitHub

Установленная программа сама проверяет последний релиз GitHub при запуске (через минуту) и затем каждые 6 часов. Если версия новее, она скачивает `VeloController.exe`, сверяет SHA-256 из `VeloController.exe.sha256`, дожидается, пока педали не крутят (2 минуты), заменяет себя и перезапускается. Флешка не нужна.

Условия: репозиторий публичный (или релизы доступны без входа) и в релизе есть оба файла - `VeloController.exe` и `VeloController.exe.sha256`.

## Выпуск новой версии

1. Внесите изменения и закоммитьте.
2. Поставьте тег и отправьте его:

   ```powershell
   git tag v4.1.0
   git push origin main --tags
   ```

3. GitHub Actions (`.github/workflows/release.yml`) соберёт exe и создаст релиз. Номер версии и имя репозитория подставляются при сборке.

Локальная сборка (для проверки, автообновление в ней отключено, т.к. репозиторий в `version.py` пуст):

```powershell
py -m pip install -r requirements.txt
py -m PyInstaller velocontroller.spec --noconfirm --distpath dist --workpath build-tmp
```

## Запуск из исходников

```powershell
py -m pip install -r requirements.txt
py pedal_controller_windows.py
```

## Файлы

- `pedal_controller_windows.py` - основная программа (контроль, Arduino, блокировка, настройки).
- `velo_gauge.py` - спидометр, фейерверк, расположение на экране.
- `velo_welcome.py` - приветственное окно с историей и календарём.
- `updater.py`, `version.py` - автообновление из релизов GitHub.
- `install_windows_task.ps1`, `INSTALL_VELOCONTROLLER.bat` - установка и автозапуск.
- Рабочие данные программы (настройки, пароль, статистика) лежат в скрытой папке `%ProgramData%\SyncCache\DeviceRuntime` и в репозиторий не попадают.
